# trifsm

trifsm is a code generator that will allow you to convert your mermaid diagrams into FSMs using [looplab/fsm](https://github.com/looplab/fsm).
Heavily inspired by [abice/go-enum](https://github.com/abice/go-enum).

## Getting Started

Install the package using `go install`:
```bash
go install github.com/fira42073/trifsm@latest # latest (may be unstable)
# or
go install github.com/fira42073/trifsm@senpai # stable branch
```
